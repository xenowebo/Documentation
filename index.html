04 — BUILD YOUR UI

Lua UI examples

Build a simple interface one component at a time. Initialize Xen0UI through your trusted method, then copy the examples below in order. Each card has its own copy button.

LightBright, clean surfaces
DarkSoft, low-light contrast
01

Create a window

Choose either "Light" or "Dark" for the window theme.

window.lua
local Window = Xen0UI:CreateWindow({
    Name = "My Xen0 UI",
    Theme = "Dark", -- Options: "Light" or "Dark"
    LoadingTitle = "My Project",
    LoadingSubtitle = "UI demo"
})
02

Add a tab and section

Tabs keep related controls neatly grouped in your window.

tab.lua
local Tab = Window:CreateTab("General")
Tab:CreateSection("Basic controls")
03

Button

A simple button with a harmless demo callback.

button.lua
Tab:CreateButton({
    Name = "Say hello",
    Callback = function()
        print("Hello from my UI")
    end,
})
04

Toggle

Print the toggle state without changing anything in-game.

toggle.lua
Tab:CreateToggle({
    Name = "Demo toggle",
    Current = false,
    Callback = function(enabled)
        print("Demo toggle:", enabled)
    end,
})
05

Slider

Try a value range and print the selected value.

slider.lua
Tab:CreateSlider({
    Name = "Example value",
    Min = 1,
    Max = 100,
    Current = 25,
    Callback = function(value)
        print("Selected value:", value)
    end,
})
06

Text input

Capture text for a demo and print it.

input.lua
Tab:CreateInput({
    Name = "Project name",
    PlaceholderText = "Type a name...",
    Callback = function(text)
        print("Project name:", text)
    end,
})
07

Dropdown

Offer a choice of themes and print the selection.

dropdown.lua
Tab:CreateDropdown({
    Name = "Color theme",
    Options = {"Light", "Dark"},
    Callback = function(selection)
        print("Selected theme:", selection)
    end,
})
08

Keybind

Show a keybind callback with a harmless message.

keybind.lua
Tab:CreateKeybind({
    Name = "Demo shortcut",
    CurrentKey = Enum.KeyCode.K,
    MasterMinimize = false,
    Callback = function()
        print("Demo shortcut pressed")
    end,
})
i

Demo snippets: callbacks only print messages; they do not change gameplay or interact with other players. The examples assume Xen0UI has already been initialized.

05 — GOOD TO KNOW

Frequently asked questions

Where should I download Xen0 Executor?

Use only the official Xen0 project page or a release source linked directly by the project. Be cautious of copycat sites and unofficial downloads.

Where do I find help with setup?

Check the release notes and official project documentation first. Include your device and the exact step you’re having trouble with when asking for support.

Can I use any script I find online?

No. Review scripts before use and only use sources you trust. Never paste code that asks for your password, tokens, or other private information.
