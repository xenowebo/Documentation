Quick start

Load the library, create a window, then add a tab and its elements. Replace the loader with your trusted distribution URL when sharing your project.

local Xen0UI = loadstring(game:HttpGet("https://raw.githubusercontent.com/ui-01/01/01/01.lua"))()

local Window = Xen0UI:MakeWindow({
    Name = "Xen0 UI",
    HidePremium = false,
    SaveConfig = true,
    ConfigFolder = "Xen0Test"
})

local Tab = Window:MakeTab({
    Name = "Main",
    Icon = "rbxassetid://4483345998",
    PremiumOnly = false
})

local Section = Tab:AddSection({ Name = "Scripts" })
